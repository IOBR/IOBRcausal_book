# Citation and support

[Book contents](../../README.md) · [Previous: Advanced analysis](advanced.md) · [Next: Original examples and figures](historical-examples.md)

Record the package version used in your analysis. A software citation does not
replace citations for the original estimators, gene-set sources or datasets.

```bibtex
@software{IOBRcausal2026,
  title   = {IOBRcausal: Comprehensive Causal Inference Toolkit for Immuno-Oncology Research},
  author  = {Liu, Linfeng and Zeng, Dongqiang},
  year    = {2026},
  version = {32.2.3},
  url     = {https://github.com/IOBR/IOBRcausal}
}
```

Use `citation("IOBRcausal")` for the citation distributed with your installed
version, and `sessionInfo()` to record the computational environment.

Report problems through [GitHub issues](https://github.com/IOBR/IOBRcausal/issues).
Include a small synthetic example, the exact error, request and version.
The package is distributed under the MIT license.
